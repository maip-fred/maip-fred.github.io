# maip-fred.github.io

CV personal y sitio web estático de Alfredo Maip, desplegado en GitHub Pages. Diseño editorial minimalista con tipografía de revista, animaciones al hacer scroll y soporte completo para dispositivos móviles.

## Tecnologías

- HTML5 semántico
- CSS3 con variables personalizadas (sistema de diseño propio)
- [TailwindCSS](https://tailwindcss.com/) via CDN — utilidades de layout y espaciado
- [AOS](https://michalsnik.github.io/aos/) — animaciones al hacer scroll
- [Lucide Icons](https://lucide.dev/) — iconografía SVG limpia
- [Google Fonts](https://fonts.google.com/) — Inter + Playfair Display
- JavaScript vanilla — sin frameworks, sin dependencias de build

## Ver localmente

```bash
# Opción 1 — abrir directamente en el navegador
# Clonar el repositorio y abrir index.html con doble clic.

# Opción 2 — live server (recomendado para ver cambios en tiempo real)
# Con la extensión Live Server de VS Code: clic derecho en index.html → "Open with Live Server"

# Opción 3 — servidor Python
python3 -m http.server 8080
# Luego abrir http://localhost:8080
```
