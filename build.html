NPM DEPS

Sin frameworks. Sin build steps. Sin npm. Solo HTML, CSS y vanilla JS — y muchas decisiones deliberadas. Este documento las explica todas.

Filosofía

Sin framework,
a propósito.

La decisión más importante fue no usar React, Vue, ni ningún framework. Un portfolio personal no necesita estado reactivo complejo — necesita cargar rápido, funcionar offline y ser legible en el source. Eso favorece HTML semántico.

Tailwind CDN cubre utility-first CSS sin build step. AOS maneja scroll animations. Lucide provee íconos. Todo vía CDN: no hay node_modules, no hay webpack, no hay CI/CD complejo.

# Lo que NO hay en este repo

package.json → no existe
node_modules/ → no existe
webpack.config → no existe
dist/ → no existe

# El deployment es literalmente:
git push origin main → listo en ~2 min

Decisiones técnicas,
en orden.

Diseño

Sistema de diseño con CSS custom properties

50+ variables en :root: paleta dark developer con acentos blue/cyan/green/purple/gold. Una sección crema para contraste editorial.

/* Tipografía triple */ --f-display: 'Cormorant Garamond'; /* headings */ --f-sans: 'DM Sans'; /* body */ --f-mono: 'JetBrains Mono'; /* UI / código */
Arquitectura

14 módulos JS — cada página carga solo lo suyo

No hay bundle monolítico. Cada módulo hace return temprano si su elemento no existe en la página.

document.addEventListener('DOMContentLoaded', () => { var el = document.getElementById('hero-term-body'); if (!el) return; // ← salida temprana });
core.jsterminal.jsparticles.jscmdk.jssound.jscursor.jsmagnetic.jsscramble.js
Feature

Terminal interactiva — 20 comandos, historia, autocomplete

Un REPL en el DOM: captura keydown global, no un input. Tab autocompleta contra el objeto COMMANDS. Boot sequence con typewriter async encadenado.

/* keydown global = sin necesidad de focus */ document.addEventListener('keydown', ht_handleKey); // Tab → autocomplete · ↑↓ → historial
Canvas

Partículas que forman palabras — pixel sampling off-screen

70 partículas que al hover se reorganizan dibujando texto (GM/HI/PM/ZZZ según la hora). Posición objetivo = píxeles no-transparentes de un canvas off-screen.

var off = document.createElement('canvas'); off.getContext('2d').fillText(word, ...); var data = off.getContext('2d').getImageData(...).data; // cada partícula → un píxel no-transparente
Animaciones

CSS animations puras — sin GSAP, sin Motion

Todas las animaciones: entradas, glitch en "Ibáñez", partículas — sin librería. Solo AOS para scroll reveals y View Transition API para cambio de página.

@keyframes glitch-1 { 0%,90%,100% { clip-path: inset(50% 0 50% 0); } 92% { clip-path: inset(15% 0 65% 0); transform: translate(-4px,1px); } 94% { clip-path: inset(55% 0 25% 0); transform: translate(4px,-1px); } }
Visual

Mesh gradient animado — blobs con filter:blur

3 divs con border-radius:50% y filter:blur(90px), cada uno con keyframe diferente. Parece un gradiente Figma que respira. Costo: 0.

.mesh-blob-1 { background: radial-gradient(circle, rgba(37,99,235,.22) 0%, transparent 70%); filter: blur(90px); animation: meshBlob1 14s ease-in-out infinite; }
Textura

Grain overlay — SVG feTurbulence a 2.8% de opacidad

Un div fijo pointer-events:none con SVG data-URI como background. feTurbulence genera ruido procedural animado.

background-image: url("data:image/svg+xml,... <feTurbulence baseFrequency='.75' numOctaves='4'/> ..."); animation: grain 8s steps(10) infinite;
Animación

Text scramble — descifrado estilo Mr. Robot

Un IntersectionObserver detecta [data-scramble]. Al entrar al viewport, decodifica de izquierda a derecha en ~1.2 s. Un solo atributo activa el efecto.

/* Un atributo, todo el efecto */ <h2 data-scramble>Habilidades técnicas</h2> <em data-scramble data-scramble-delay="300">rápida.</em>
Interacción

Magnetic buttons — atracción al cursor dentro de 90px

Fuerza proporcional a la distancia. El ícono interno recibe movimiento inverso más suave para profundidad 3D. Spring-back con cubic-bezier(0.22,1,0.36,1).

var pull = (1 - dist / RADIUS) * STRENGTH; btn.style.transform = `translate(${dx*pull}px, ${dy*pull}px)`;
Performance

PWA + Service Worker cache-first — funciona offline

js/sw.js sirve recursos cacheados primero; red solo como fallback. El manifest.json permite instalación como app nativa.

# Resultado: instalable como app nativa Chrome → "Instalar Alfredo Ibáñez — Home" Mobile → "Agregar a pantalla de inicio" # Sin conexión → sigue funcionando
Audio

Sound design opt-in — Web Audio API, cero archivos .mp3

Todos los sonidos son procedurales: OscillatorNode + GainNode. El tick del typewriter es onda cuadrada 2000 Hz / 40 ms.

var osc = ctx.createOscillator(); osc.type = 'square'; osc.frequency.value = 2000; gain.gain.setTargetAtTime(0, ctx.currentTime+.03, .01); osc.start(); osc.stop(ctx.currentTime + .04);
Easter egg

Matrix rain — Katakana + canvas, activado desde la terminal

En lugar de clearRect, un fillRect negro al 6% crea el trail. Escribe matrix en la terminal para activarlo.

/* Trail: no clearRect, semi-transparent fill */ ctx.fillStyle = 'rgba(0,0,0,0.06)'; ← fade ctx.fillStyle = '#00ff41'; ctx.fillText(char, x, y);
Browser API

View Transition API — fade/slide nativo entre páginas

Links con data-t interceptan el click y llaman document.startViewTransition() si está disponible (Chrome 111+). Fallback: clase .leaving con fadeOut de 380 ms.
