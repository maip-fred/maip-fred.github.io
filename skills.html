Lo que me diferencia

Soft skills — habilidades que no aparecen en un pip install

Pero que hacen funcionar a un equipo. Estas competencias son el pegamento entre el código y la colaboración.

Pensamiento analítico

Descompongo problemas complejos en partes manejables antes de escribir una línea de código.

Resolución de problemas

Encuentro la raíz, no el síntoma. Método sobre intuición — cada bug tiene una historia.

Trabajo en equipo

PRs limpios, commits coherentes. El contexto compartido es parte del trabajo bien hecho.

Comunicación efectiva

Explico código y decisiones con la claridad que el siguiente dev necesita para entender.

Atención al detalle

El edge case que otros omiten es el que me obsesiona hasta resolverlo completamente.

Aprendizaje continuo

Rust, Finanzas I, papers de supply-chain — todo en paralelo, sin disculpas, siempre.

Gestión del tiempo

8° semestre + proyectos propios + portfolio. Aprendo a priorizar haciendo.

Pensamiento crítico

Cuestiono los supuestos, incluyendo los míos. La duda metodológica como herramienta.
