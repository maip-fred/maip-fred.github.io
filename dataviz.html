Dashboards reactivos · Práctica 03

Shiny:
todo en vivo.

Apps web interactivas directamente en R — sin tocar JavaScript. El paradigma reactivo reconecta el análisis estadístico con la UI: cada cambio en un input dispara re-ejecución automática de outputs.

ui.R — Interfaz (fragmento clave)

ui <- fluidPage(
  sidebarLayout(
    sidebarPanel(
      sliderInput("bins", "Bins:",
        min=5, max=50, value=20)),
    mainPanel(
      plotOutput("histogram"))))

server.R — Lógica reactiva (fragmento clave)

# Re-ejecuta al cambiar input
server <- function(input, output) {
  output$histogram <- renderPlot({
    x <- faithful[, 2]
    bins <- seq(min(x),max(x),
      length.out=input$bins+1)
    hist(x, breaks=bins,
      col="#3B82F6")})
}
